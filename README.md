# Nv-studio Tap

## How do I install these formulae?

`brew install nv-studio/tap/openssh-pal`

Or `brew tap nv-studio/tap` and then `brew install --cask nv-studio/tap/openssh-pal`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nv-studio/tap"
brew "openssh-pal"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
